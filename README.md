## 🌟 Descrição
Este projeto cria uma **página web simples e funcional** que funciona como um diretório de filmes e séries.  
O usuário pode digitar o nome de um filme ou série no campo de pesquisa e clicar em **Pesquisar**.  

- A pesquisa verifica tanto o **título** quanto a **descrição** de cada item.  
- Quando há correspondência, o item é exibido com:  
  - Título  
  - Imagem  
  - Link para assistir na plataforma de streaming correspondente.  

Cada item possui informações básicas, permitindo uma navegação clara e objetiva.

---

## 🛠️ Como Funciona

### HTML
Define a **estrutura da página**, criando elementos como:  
- Cabeçalho  
- Corpo  
- Rótulos e campos de entrada  
- Botões  
- Lista de resultados

### CSS
Responsável pela **estilização da página**, incluindo:  
- Layout  
- Fontes  
- Aparência geral e cores

### JavaScript
Adiciona **interatividade**, permitindo que a pesquisa funcione:  
1. Captura o texto digitado pelo usuário.  
2. Percorre todos os elementos que representam filmes ou séries.  
3. Verifica se o título ou a descrição contém o termo pesquisado.  
4. Mostra o item correspondente ou o oculta, conforme o resultado.

---

## 🎯 Em Resumo
O site funciona como um **mecanismo de busca simples** para uma lista pré-definida de filmes e séries:  

- O usuário insere um termo de busca.  
- O site filtra e exibe apenas os itens relevantes.  
- A interface é **intuitiva**, facilitando a navegação e a consulta de informações.
